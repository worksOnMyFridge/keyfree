How it works

1

The agent asks

The agent's NEAR key can only call the request methods; rules, roles and upgrades belong to a council of three humans.

2

A contract on NEAR decides

The policy is a NEAR contract with no access keys. It holds the rules: which init code may be deployed, on which chains, with which caps and daily budget.

3

NEAR MPC signs

The policy builds the EVM transaction itself and asks NEAR MPC to sign it for its own derived address. It never signs a hash someone hands it.

Why now

Teams lose real money when one key can upgrade their contracts. In each case below a single stolen key was enough (sources).

  • Wasabi Protocol, April 2026: about $5 million.
  • Zoth, March 2025: about $8.4 million.
  • DeltaPrime, September 2024: nearly $6 million.

Each was one stolen key that could upgrade contracts.
